# MD Alif Shikder — Portfolio Website

## ফাইলগুলো কী?
- `index.html` — ওয়েবসাইটের লেখা ও section structure।
- `style.css` — কালার, ডিজাইন, spacing, responsive layout এবং animation।
- `script.js` — scroll animation, navbar effect ও ছোট interaction।

## কীভাবে চালাবেন?
1. ZIP extract করুন।
2. `index.html` ফাইলে double-click করুন, অথবা VS Code-এ folder খুলে Live Server দিয়ে চালান।
3. Bootstrap, Bootstrap Icons এবং Google Fonts CDN ব্যবহৃত হয়েছে; এগুলো লোড হতে internet লাগবে।

## নিজের মতো পরিবর্তন করবেন
- নাম/পরিচিতি: `index.html`-এ `MD Alif Shikder` লিখে search করুন।
- Email: `index.html`-এ `YOUR_EMAIL@example.com` খুঁজে নিজের email বসান।
- Social links: `index.html`-এ GitHub, Facebook, TikTok ও Instagram-এর `href` বদলান।
- Skills / Services: `index.html`-এর সংশ্লিষ্ট section-এর text বদলান।
- Main color: `style.css`-এর একদম উপরের `:root` অংশে `--blue`, `--cyan`, `--bg` পরিবর্তন করুন।
- Font size / spacing: `style.css`-এ `.hero-title`, `.section-space` ইত্যাদি class খুঁজে edit করুন।
- Profile initials: `index.html`-এ `AS` বদলে নিজের পছন্দের initials দিন।

## গুরুত্বপূর্ণ
- আপনার অনুরোধ অনুযায়ী কোনো live/client project বা ভুয়া project showcase যোগ করা হয়নি।
- Contact button-এ placeholder email আছে। প্রকাশ করার আগে নিজের সঠিক email বসাবেন।
- এই portfolio-তে Bootstrap 5 CDN ও Bootstrap Icons CDN ব্যবহার করা হয়েছে।
- সব code section-এ English comments দেওয়া আছে, যাতে পরে সহজে বুঝে edit করতে পারেন।
